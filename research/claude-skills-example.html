## requirements.md

### Functional Requirements
- FR1: User can create, edit, delete tasks
- FR2: User can set due dates and reminders
- FR3: User can mark tasks as complete / incomplete
- FR4: User can create shared lists and invite teammates
- FR5: User can assign tasks to specific team members
- FR6: User receives notifications for due tasks
- FR7: User can filter tasks by status, due date, assignee

### Non-Functional Requirements
- NFR1: App loads in <2s on mobile (3G)
- NFR2: Supports 10,000 concurrent users
- NFR3: Data encrypted at rest and in transit
- NFR4: 99.9% uptime SLA

- Pain point: No single view of who is doing what
