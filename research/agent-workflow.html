LOOP Agent #13
Fix Agent Loop
▼
Loop Logic
  • →Receive bug_report.json from QA Agent
  • →Classify bug: Critical / High / Medium / Low
  • →Assign bug to correct Junior agent by module
  • →Junior agent implements fix
  • →Senior agent reviews the fix
  • →QA Agent retests specific bug
  • →If pass → mark resolved, continue loop
  • →If fail → retry (max 3 attempts per bug)
  • →3rd attempt fails → Escalate to Senior Agent
  • →Senior cannot fix → HITL escalation to human
Exit Conditions
  • →✅ All Critical & High bugs resolved
  • →⚠️ Remaining bugs are Medium/Low → log to backlog
  • →🚨 Blocker bugs → human notified, pipeline paused
Retry Rules
  • →Max 3 attempts per bug at Junior level
  • →Each retry adds specific context from last failure
  • →Medium/Low bugs: 1 attempt, then backlog
